SITE DEMONSTRATIVO PARA SALÃO
=============================

ARQUIVOS
- index.html: estrutura e conteúdo da página.
- css/style.css: cores, tipografia, layout e responsividade.
- js/main.js: menu móvel e comportamento demonstrativo do formulário.
- assets/images/: pasta para colocar as fotos reais quando o cliente aprovar.

COMO ABRIR
1. Extraia a pasta amostra_salao.zip.
2. Abra a pasta amostra_salao no VS Code.
3. Abra index.html no navegador. Se tiver a extensão Live Server, clique com o botão direito em index.html e escolha "Open with Live Server".

PERSONALIZAÇÃO
- Procure "Seu Salão", "Nome do serviço", "Endereço do seu salão" e "@seuinstagram" no index.html.
- Os blocos de imagem são placeholders intencionais; não há fotos de outras empresas.
- Para colocar uma imagem, substitua o bloco .image-placeholder pelo elemento <img src="assets/images/nome-da-foto.jpg" alt="Descrição da imagem"> e ajuste a classe CSS.
- Atualize o endereço e o mapa quando receber os dados corretos.
- No js/main.js, preencha whatsappNumber com o número internacional do salão, somente dígitos, por exemplo 5511999999999.
- O formulário é demonstrativo. Sem configurar WhatsApp ou backend, ele não envia dados para um servidor.
- O perfil e a galeria do Instagram são uma prévia visual, não um feed real conectado à plataforma.

OBSERVAÇÃO
O site usa fontes do Google Fonts; sem internet, o navegador usa fontes alternativas. O site é responsivo e não depende de frameworks.
